# 贪吃蛇游戏 (Snake Game)

~~这是一个基于 Java Swing 开发的经典贪吃蛇游戏~~

这是一个基于cursor(Gemini 2.5 Flash) 开发的经典贪吃蛇游戏
## 游戏介绍

在这个游戏中，玩家控制一条在限定区域内移动的蛇。蛇通过吃掉随机出现的食物来增长身体，并获得分数。游戏的目标是尽可能多地吃掉食物，使蛇身变长，同时避免撞到墙壁或自己的身体。

## 游戏玩法

*   **控制**: 使用键盘上的 **方向键 (上、下、左、右)** 来控制蛇的移动方向。
*   **得分**:
    *   每吃到一个食物，分数增加 100。
    *   每经过一段时间，分数也会自动上涨（时间分）。
*   **游戏结束**:
    *   当蛇头撞到游戏区域的边界时，游戏结束。
    *   当蛇头撞到自己的身体时，游戏结束。
*   **重新开始**: 游戏结束后，可以按下 **空格键** 或用 **鼠标点击** 游戏窗口来重新开始游戏。

## 运行方法

### 前提条件

确保你的计算机上安装了 **Java 17 或更高版本** 的 Java 运行时环境 (JRE)。

### 通过 Maven 运行 (需要安装 Maven)

如果你安装了 Apache Maven，可以在项目根目录 (即包含 `snake` 文件夹的目录) 下打开终端，并执行以下命令：

1.  **编译并运行**:
    ```bash
    mvn clean install -f snake/pom.xml
    mvn exec:java -f snake/pom.xml
    ```

### 通过可执行 JAR 文件运行 (推荐给非开发人员)

我们提供了预编译的可执行 JAR 文件和方便的启动脚本，让你可以更轻松地运行游戏。

1.  **打包游戏 (如果尚未打包)**:
    在项目根目录 (即包含 `snake` 文件夹的目录) 下打开终端，并执行以下命令来生成可执行 JAR 文件：
    ```bash
    mvn clean package -f snake/pom.xml
    ```
    这会在 `snake/target/` 目录下生成一个名为 `snake-1.0-SNAPSHOT.jar` 的文件。

2.  **使用启动脚本运行**:
    *   **Windows 用户**: 双击项目根目录下的 `run_game.bat` 文件即可启动游戏。命令行窗口将自动关闭。
    *   **Linux / macOS 用户**: 打开终端，导航到项目根目录，然后执行以下命令赋予脚本执行权限并运行：
        ```bash
        chmod +x run_game.sh
        ./run_game.sh
        ```

## 开发过程

这个贪吃蛇游戏是在一个现有的 Java Maven 项目框架基础上逐步构建的，主要实现了以下功能：

*   **游戏窗口**: 使用 Swing 库创建了可调整大小的游戏窗口。
*   **游戏面板**: 实现了 `GamePanel` 类来处理游戏逻辑和图形绘制。
*   **蛇与食物**: 实现了蛇的绘制、移动和食物的随机生成。
*   **用户输入**: 通过键盘监听器实现了对蛇移动方向的控制。
*   **游戏逻辑**:
    *   蛇的移动逻辑。
    *   吃到食物后蛇身增长和分数增加。
    *   碰撞检测（与墙壁和自身）。
*   **得分机制**: 实现了吃到食物得分和基于时间自动增长的分数。
*   **游戏结束与重启**: 游戏结束后显示 "Game Over" 和分数，并支持通过空格键或鼠标点击重新启动游戏。
*   **自动化运行**: 提供了 Windows (`.bat`) 和 Linux/macOS (`.sh`) 的一键运行脚本。
